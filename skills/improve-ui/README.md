# `improve-ui` Skill

A production-grade, globally available Antigravity skill that improves and polishes the visual design and UX of an existing application's UI **without breaking any functionality** and **without making the result look vibe-coded or AI-generated**.

## Quick Invocation
In any project conversation, type:
`/improve-ui`
or ask:
> "Improve the UI of the checkout page"
> "Polish the spacing and typography on this dashboard"
> "Make this screen look cleaner and more modern"

## Package Structure
- `SKILL.md`: Main workflow orchestrator (Phases 0–5, Safety Rails, 8 Verification Gates).
- `references/anti-ai-look.md`: Strict rules against generic AI styling tropes, plus the 5-point smell test.
- `references/design-audit-checklist.md`: 9-category design audit checklist with severity ratings.
- `references/verification-gates.md`: Comprehensive guide to the 8 Verification Gates and diff isolation.
- `templates/functional-contract.md`: Pre-change contract artifact guaranteeing frozen behavior.
- `templates/final-report.md`: Structured delivery report.
- `scripts/diff-audit.sh`: Automated diff inspection script flagging non-presentational changes.
- `evaluations/test-cases.md`: 3 realistic evaluation prompts and step-by-step verification audits.
